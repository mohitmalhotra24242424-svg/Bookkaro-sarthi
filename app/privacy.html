Privacy

Simple language, short page — jaise hona chahiye.

Kya data use hota hai

Aapke chat messages aur journey details (station, date, passengers) — sirf aapka request process karne ke liye. Is page ka chat input seedha assistant ke paas jaata hai.

API keys aur credentials

Saare provider keys sirf secure server par rehte hain — browser, chat ya logs mein kabhi expose nahi hote.

PNR numbers

PNR status check karne ke liye hum aapka PNR number sirf railway data provider ko bhejte hain — store karke advertise nahi karte.

Cookies / tracking

Koi advertising ya tracking nahi. Sirf ek local setting (chat ka server URL) browser mein save hoti hai, jab aap khud set karte ho.

Payments

Abhi koi real payment process nahi hota — booking demo flow hai, explicit confirmation ke saath.

Sawal ho toh chat mein “help” likhein, ya wapas homepage par jaayein.
